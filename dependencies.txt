cffi,"Low-level interface to C libraries from Python (used by pymunk, moderngl)."

glcontext,Creates standalone OpenGL contexts for testing shaders without a window.

llvmlite,LLVM backend for numba — enables JIT compilation of Python to machine code.

moderngl,Modern OpenGL wrapper for writing shaders and rendering with GPU acceleration.

noise,"Generates Perlin/simplex noise for procedural terrain, caves, biomes."

numba,"Speeds up math-heavy Python code (e.g. pathfinding, simulation) via JIT."

numpy,Fast array math — core of all tile/chunk/world data in your game.

pillow,"Load/save images (PNG, JPG) — used for textures, sprites, UI assets."

pip,Python package installer — manages all your dependencies.

py-spy,Live profiler — sample CPU usage of running game to find bottlenecks.

pycparser,Parses C code — used internally by cffi to generate bindings.

pygame,"Main game loop, input, sound, and window — your core engine."

pygame-ce,Community edition of Pygame with bug fixes and performance improvements.

pygame_gui,"Ready-made UI elements (buttons, panels, text) on top of Pygame."

pymunk,"2D physics engine (Chipmunk) — collisions, gravity, rigid bodies."

PyPDF2,Read/write PDF files — likely for generating in-game manuals or debug docs.

python-i18n,Simple internationalization — supports multiple languages via YAML files.

PyTMX,Loads Tiled .tmx maps — lets you design levels in Tiled editor.

pytweening,Easing functions (smooth in/out) — for animations and camera moves.

pydantic,Validates and parses config/data (like spawn rules) with zero boilerplate.

loguru,"Drop-in, beautiful logging with colors, files, and no config needed."

tqdm,Shows progress bars for long loops (e.g. world generation).

snakeviz,Visualizes cProfile output — helps debug performance hotspots.

tornado,"Async web server — likely for dev tools, hot-reload, or debug dashboard."
